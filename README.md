# hh-job-apply-bot

MVP web-приложения для поиска вакансий на HH.ru, оценки совпадения с профилем резюме и ручного запуска откликов через видимый браузер Playwright.

## Ограничения безопасности

- CAPTCHA не обходится. Если HH показывает CAPTCHA, процесс останавливается и пишет ошибку в лог.
- Автоотклики запускаются только вручную через интерфейс.
- При ошибке авторизации процесс останавливается.
- Перед действиями отклика используется настраиваемая задержка из Settings. Для теста по умолчанию стоит 3-8 секунд.
- Дневной лимит задается в Settings и учитывается при Auto Apply.

## Локальный portable Node.js

В проект добавлен portable Node.js в папку .tools и три helper-скрипта:

- install-and-run.cmd - установить зависимости, применить миграции, поставить Playwright browsers и запустить проект.
- start-project.cmd - запустить проект после установки зависимостей.
- node-shell.cmd - открыть терминал с настроенным PATH на portable Node.

Если запускать из обычного Windows Explorer или терминала, используйте install-and-run.cmd для первого старта.


## VS Code: node не найден

Если в терминале VS Code команда node -v не работает, закройте текущий терминал и откройте новый: Terminal -> New Terminal. В проект добавлена настройка .vscode/settings.json, которая добавляет portable Node.js в PATH новых терминалов.

Для уже открытого PowerShell-терминала можно выполнить:

~~~powershell
.\use-node.ps1
~~~

После этого команды node, npm и npx будут доступны в этом терминале.

## Как войти в HH

1. Откройте Dashboard.
2. Нажмите "Войти в HH".
3. В открывшемся видимом браузере войдите в аккаунт HH вручную.
4. После успешного входа сессия сохранится в hh-auth.json.

Если HH показывает CAPTCHA, решать или обходить ее приложение не будет. Процесс остановится, а событие появится в логах.

## Как запустить поиск

1. Откройте Settings.
2. Заполните ключевые слова, города, минимальную зарплату и профиль резюме для match score.
3. При необходимости включите поиск по всей России или только удалённой работы и укажите количество новых вакансий.
4. Вернитесь на Dashboard.
5. Нажмите "Запустить поиск".
6. Найденные вакансии появятся на странице Vacancies.

Повторный поиск не добавляет уже известные ссылки, даже если список вакансий был очищен. Автоотклик работает только с новыми вакансиями последнего успешно завершённого поиска.

Статусы вакансий:

- found - вакансия найдена, но match score ниже базового порога.
- pending - вакансия ожидает отклика.
- applied - отклик отправлен или уже был отправлен ранее.
- skipped - вакансия пропущена вручную.
- failed - отклик завершился ошибкой.

## Как откликнуться вручную

1. Откройте Vacancies.
2. Нажмите кнопку с иконкой отправки в строке вакансии.
3. Playwright откроет вакансию в видимом браузере и нажмет кнопку отклика только после этой команды.

## Как включить автоотклики

1. Откройте Auto Apply.
2. Укажите любое количество откликов от 1 до 1000.
3. Нажмите Start.
4. Для остановки нажмите Stop.

Auto Apply берет найденные вакансии со статусом found или pending без ограничения по match score, соблюдает дневной лимит и останавливается при CAPTCHA или ошибке авторизации.

## Задержка отклика

В Settings можно настроить задержку перед нажатием кнопки отклика и перед отправкой формы. Для быстрого теста используйте 3-8 секунд. Для более осторожного режима можно поставить 60-180 секунд.
