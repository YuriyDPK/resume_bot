# Развёртывание

Публикация выполняется GitHub Actions после успешных проверок при push в `prod`. Секрет `RESUME_BOT_DEPLOY_KEY` используется только для SSH и ограничен серверной командой `/usr/local/sbin/resume-bot-deploy`. Подменённый ключ сервера отклоняется благодаря зафиксированному ключу хоста в workflow.

Служба `resume-bot.service` запускает приложение на `127.0.0.1:3013`; nginx предоставляет публичный доступ по HTTPS. Профили, SQLite и сессия HH хранятся в `/var/lib/resume-bot`, отдельно от версий приложения в `/opt/resume-bot/releases`. Перед миграцией SQLite сохраняется резервная копия; при неудачной миграции или запуске восстанавливаются прежняя база и версия. Запуск обновления останавливает текущую задачу бота.

На сервере установлен изолированный Node в `/opt/resume-bot/node`; файлы `/usr/local/sbin/resume-bot-deploy`, `/etc/systemd/system/resume-bot.service` и `/etc/nginx/conf.d/resume-bot.conf` устанавливаются администратором при первоначальной настройке. Их изменения в репозитории не применяются к серверной конфигурации автоматически. Certbot обновляет сертификат через webroot `/var/www/resume-bot-acme` и перезагружает nginx после обновления.

Это один общий экземпляр приложения: всем посетителям сайта доступны его настройки, история и подключённый аккаунт HH. Никакие локальные базы или сохранённые сессии с компьютера не загружаются при публикации.
